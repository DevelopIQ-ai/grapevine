Two enumeration lanes trade query-lottery for completeness: `hn-enum` walks the whole date window in ~12h Algolia buckets (every HN story posted) and `github-enum` lists every public repo created in the window, most-starred first — each lane's first query returns the full slice and Jev judges every item. `LAST30DAYS_X_DIG_ENUMERATE=0` disables; `LAST30DAYS_X_DIG_ENUM_MAX` (default 4000) bounds per-lane Jev volume. The planner and Judge now also retry malformed-model-output failures with the same exponential-backoff policy as transport errors, and the failure message names which contract field was violated.

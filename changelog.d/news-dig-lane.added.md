Add a keyless Google News lane to the iterative dig: every dig round also fires
follow-up queries at news.google.com's RSS search — free, no API key — so news
coverage of launches and announcements is dug alongside X, Hacker News, and the
configured web backend. Select it (or exclude it) with `googlenews` (alias
`news`) in `LAST30DAYS_X_DIG_SOURCES`.
